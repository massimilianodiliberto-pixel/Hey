# Volto di Giangi — prova

Fotogrammi del sito, a circa 4 secondi l'uno dall'altro, con testi e lavori nascosti solo per la prova.
- `salto-1..3.jpg`: capitolo Salto.
- `composizione-1..3.jpg`: capitolo Composizione.
- `tavola.jpg`: i sei fotogrammi affiancati.

Punti e linee vengono dalla foto (riferimenti/volto-giangi/), la profondità dalla maglia 3D (maglia.json). Il lato in ombra è ricostruito per simmetria.
