# Proposta 5 — dentro la testa di Giangi

Collegamenti neuronali organici: ogni esperienza è un nodo-ricordo, i sensi sono le connessioni.
Filamenti come inchiostro o dendriti al microscopio, buio del teatro di posa, sola luce calda che
scorre nei filamenti, profondità di campo, grana leggera. Niente blu, niente glow da fantascienza.

1. `rete-1.jpg` — Apertura: nel buio si accende il primo ricordo.
2. `rete-2.jpg` — Il ricordo si apre dal suo nodo: il primo spot e le copertine, senso dell'immagine.
3. `rete-3.jpg` — Salto «prima»: la camera segue il segnale lungo il filamento verso un ricordo lontano.
4. `rete-4.jpg` — Arrivo: tutte le connessioni accese insieme, l'Istinto.

Prototipo veloce in Three.js (profondità di campo e grana in post-produzione), fuori dal sito.
